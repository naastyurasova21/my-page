# Очень странные дела — фан-сайт

Учебный проект по вёрстке: одностраничный сайт, посвящённый сериалу «Очень странные дела».

## Что внутри

- `index.html` — структура страницы
- `styles.css` — оформление и адаптация под мобильные
- `app.js` — интерактивные элементы
- `images/` — изображения

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, CSS-переменные, медиа-запросы)
- JavaScript (без библиотек)
- Google Fonts, Font Awesome

## Функциональность

- Переключение светлой и тёмной темы
- Карусель персонажей со стрелками и точками навигации
- Блок «Интересные факты» с эффектом печатной машинки
- Секретный блок с пасхалкой
- Кнопка «Наверх»
- Адаптивная вёрстка для телефонов и планшетов
